# 결과 보고서

> 양성이든 음성이든 같은 틀로 쓴다. 숫자마다 분모와 기간을 붙인다.

## 1. 결론 한 줄

(적용 / 미적용 / 판단 보류) + 이유 한 문장

## 2. 설계 점검

- [ ] 그룹 표본 비율이 설계와 맞는다 (SRM 점검)
- [ ] 배정 로그가 정상이다
- [ ] 실험 기간과 대상이 설계서와 같다. 다르면 사후 변경으로 적는다

## 3. 결과

|---|---|---|---|---|---|

- 음성이면: 이 표본으로 탐지 가능했던 최소 효과(MDE) ______, 신뢰구간 상한 ______

## 4. 해석

- 실험 전에 몰랐던 것 중 무엇이 확인됐나
- 사전에 정하지 않은 하위그룹 결과는 "탐색적"으로 따로 적는다

## 5. 한계와 다음 실험
