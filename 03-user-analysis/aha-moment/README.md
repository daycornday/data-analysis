# 아하모먼트 문턱 고르기: aha-ratio 대신 MCC

온보딩 목표를 정할 때 "가입 후 7일 안에 행동 X를 N회 하면 잔존한다" 같은 아하모먼트 문장을 자주 만듭니다. 그런데 N을 어떤 지표로 고르느냐에 따라 목표가 두 배 가까이 달라져서, 흔히 쓰는 aha-ratio = TP / (TP + FP + FN)을 그대로 믿어도 되는지 궁금했습니다. 특히 잔존 유저가 소수(10% 안팎)인 데이터에서 이 지표가 어떻게 움직이는지, 대안은 무엇인지 확인해 봤습니다.

## 결과

정리하면 aha-ratio는 사실상 자카드 지수라서, 불균형 데이터에서는 기저율 근처에 눌린 채 작은 N(6)을 고르는 경향이 있었습니다. MCC는 혼동행렬 네 칸을 모두 쓰기 때문에 N = 10~18 구간이 고원처럼 평평하게 드러났고, 최고점은 12였습니다.

합성 유저 50,000명 중 잔존은 5,869명(기저율 11.74%)입니다. N을 1~30으로 훑었더니 aha-ratio는 N = 6(12.58%)을, MCC는 N = 12(0.0807)를 골랐습니다.

aha-ratio의 최댓값은 무정보 기준선(전원 "남음" 예측 = 기저율 11.74%)보다 0.84%p 높을 뿐이었습니다. 같은 N = 1~8 구간에서 MCC는 0.0392에서 0.0742로 두 배 가까이 벌어져서, 문턱 사이의 차이를 훨씬 잘 보여 줬습니다.

MCC는 N = 10~18에서 0.0751~0.0807로 거의 평평했습니다(N = 15만 최댓값의 95% 아래). 그래서 최고점 하나보다 고원으로 읽는 편이 맞다고 봤습니다. 고원 양 끝은 리프트 1.43배(N = 10, 도달 19.8%)와 1.71배(N = 18, 도달 8.4%)입니다.

다만 MCC 최댓값 0.0807은 R² 0.65%에 해당합니다. 문턱 하나의 판별력은 약한 편이라, "N = 12가 아하모먼트"라고 말하기보다 "N = 10~18 구간 유저는 남을 확률이 평균의 1.4~1.7배"라고 말하는 편이 정직하다고 생각합니다.

## 어떻게 했나

1. 먼저 합성 데이터를 만들었습니다 (`src/aha_moment_mcc/data.py`, 시드 20261020). 유저마다 숨은 관여도 z를 뽑고, z로부터 7일 안 핵심 행동 횟수와 4주차 잔존을 각각 따로 뽑았습니다. 행동이 잔존을 만들지 않도록 일부러 이렇게 짰습니다.

   ```python
   z = rng.normal(size=n)
   count = rng.negative_binomial(1.0, 1.0 / (1.0 + np.exp(1.6 + 0.7 * z)))
   retained = rng.random(n) < 1 / (1 + np.exp(-(-2.15 + 0.6 * z)))
   ```

2. "count >= N이면 남을 것"으로 예측해서 혼동행렬의 TP, FP, FN, TN을 셌습니다.
3. aha-ratio를 다시 들여다보니 자카드 지수와 같았습니다. 행동자 집합 A(TP + FP)와 잔존자 집합 B(TP + FN)의 교집합 / 합집합인데, 포함배제로 합집합은 TP + FP + FN이고 TN만 빠집니다. 그래서 전원을 "남음"으로 예측하면 값이 기저율과 같아집니다.

   $$\text{aha-ratio} = \frac{TP}{TP + FP + FN}$$

4. MCC는 네 칸을 모두 씁니다. 0/1 예측과 0/1 실제의 피어슨 상관계수(파이 계수)와 같아서, 기저율과 관계없이 무정보 기준선이 0입니다.

   $$\text{MCC} = \frac{TP \times TN - FP \times FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

5. 마지막으로 N = 1~30마다 예측 양성 비율, 정밀도, 재현율, 리프트(정밀도 / 기저율), MCC, aha-ratio를 계산했고, MCC가 최댓값의 95% 이상인 N을 고원으로 봤습니다.

## 자세히 보기

![aha-ratio와 MCC 곡선](outputs/aha_vs_mcc.png)

이 그림에서 차이가 가장 잘 보입니다. aha-ratio(위)는 기저율 점선 근처에서 거의 움직이지 않다가 N이 커지면 빠르게 떨어집니다. N이 커질수록 "행동은 덜 했지만 남은 사람"(FN)이 합집합에 쌓이기 때문이고, 그래서 구조적으로 작은 N 쪽으로 쏠리는 것으로 보입니다. 반면 MCC(아래)는 0에서 시작하는 기준선 위에서 문턱 사이의 차이를 드러냅니다.

무정보 예측기와도 비교해 봤습니다 (`outputs/baselines.csv`). 정확도는 아무것도 안 하는 예측기가 88.26%로 가장 높게 나와서 기준으로 쓸 수 없었고, 세 예측기 모두 0 근처로 나온 건 MCC뿐이었습니다.

| 예측기 | 정확도 | aha-ratio | MCC | 정밀도 | 재현율 |
|---|---|---|---|---|---|
| 전원 "안 남음" | 88.26% | 0.00% | 0 (정의상) | 정의 불가 | 0.00% |
| 전원 "남음" | 11.74% | 11.74% (= 기저율) | 0 (정의상) | 11.74% | 100.00% |
| 동전 던지기 50% | 49.89% | 10.54% | 0.0008 | 11.76% | 50.28% |

N = 12의 혼동행렬을 보면 TN이 37,693명(전체의 75.4%)으로 가장 큰 칸인데, aha-ratio는 바로 이 칸을 버립니다.

| | 실제로 남음 | 실제로 안 남음 |
|---|---|---|
| 12회 이상 | TP 1,391 | FP 6,438 |
| 11회 이하 | FN 4,478 | TN 37,693 |

MCC 공식으로 구한 값 0.080710과 `np.corrcoef(예측, 실제)` 값 0.080710의 차이는 1.25e-16(부동소수점 오차)이었습니다. 분자를 쪼개 보면 잘 맞힌 정도(TP x TN / 분모) 0.1793에서 헛짚은 정도(FP x FN / 분모) 0.0986을 뺀 값입니다.

각 기준으로 고른 문턱을 나란히 놓아 봤습니다 (`outputs/picked_thresholds.csv`, 전체 표는 `outputs/threshold_sweep.csv`).

| 기준 | N | 도달 비율 | 정밀도 | 재현율 | 리프트 | MCC | aha-ratio |
|---|---|---|---|---|---|---|---|
| aha-ratio 최고 | 6 | 34.3% | 15.0% | 43.8% | 1.28 | 0.0731 | **12.58%** |
| MCC 고원 왼쪽 끝 | 10 | 19.8% | 16.8% | 28.4% | 1.43 | 0.0782 | 11.80% |
| MCC 최고 | 12 | 15.7% | 17.8% | 23.7% | 1.51 | **0.0807** | 11.30% |
| MCC 고원 오른쪽 끝 | 18 | 8.4% | 20.1% | 14.3% | 1.71 | 0.0780 | 9.10% |

해석할 때는 질문을 두 개로 나눠서 생각했습니다. 하나는 누가 남을지 가장 잘 가르는 선(예측 문턱)이고, 이건 MCC 기준 N = 10~18 고원입니다. 다른 하나는 유저를 어디까지 끌어올리게 할지(개입 문턱)인데, 이건 고원 안에서 도달 비용과 커버리지 목표를 보고 골라야 합니다. N = 10은 넓게(이미 19.8% 도달, 리프트 1.43배), N = 18은 좁고 정밀하게(8.4% 도달, 리프트 1.71배) 잡는 선택입니다. 이 선택은 통계가 아니라 비즈니스 쪽 판단으로 정해야 한다고 봤습니다.

## 아쉬운 점과 다음에 해 볼 것

가장 조심해야 할 부분은 문턱이 상관일 뿐 인과가 아니라는 점입니다. 이 데이터에서 행동 횟수와 잔존은 둘 다 숨은 관여도에서 나왔고, 행동이 잔존을 만들지 않습니다. 유저에게 억지로 12번을 시켜도 잔존은 오르지 않습니다. 실제 서비스에서도 원래 관여도가 높은 유저가 행동도 많이 하고 오래 남는 경우가 흔합니다. 아하모먼트는 "개입해 볼 만한 후보"를 알려 줄 뿐이고, 문턱 도달을 유도하는 개입을 A/B 테스트로 돌려 잔존 차이를 봐야 효과를 말할 수 있습니다.

MCC 최댓값 0.0807(R² 0.65%)은 관례상 약한 연관(절댓값 0.1 미만)입니다. 방법을 제대로 밟았다는 것과 결과가 쓸 만하다는 것은 다른 이야기라서, 둘을 같이 보고해야 한다고 생각합니다.

고원의 폭과 최고점은 표본 변동에 흔들릴 수 있습니다. 다음에는 부트스트랩으로 N별 MCC 신뢰구간을 붙여서 "N = 12"와 "N = 18"이 통계적으로 구분되는지 확인해 보려고 합니다.

이번에는 행동 하나, 기간 하나(7일)만 봤습니다. 실무에서는 행동 종류와 기간(N일)도 같이 훑어야 하고, 그만큼 다중 비교로 우연히 높은 조합이 뽑힐 위험도 커집니다.

동전 던지기 예측기는 별도 난수(시드 20261021)로 뽑아서 원고(49.83%, 10.51%, -0.0002)와 소수점 값이 조금 다릅니다. MCC가 0 근처라는 결론은 같습니다.
