# 방법 고르기

효과를 재고 싶을 때 위에서부터 답하며 내려간다. 끝에 닿은 문서를 읽는다. "작성 예정" 문서는 [로드맵](roadmap.md)에 순서가 있다.

```mermaid
flowchart TD
    A["효과를 재고 싶다"] --> B{"무작위로 나눌 수 있나?"}
    B -- 예 --> C{"유저 단위로 나눌 수 있나?"}
    C -- 예 --> D["A/B 테스트<br>먼저 표본 크기부터"]
    C -- "아니오<br>(네트워크 효과, 매장, 지역)" --> E["클러스터 무작위화<br>또는 지역 실험"]
    C -- "아니오<br>(시간대마다 상호작용)" --> F["스위치백 실험"]
    B -- 아니오 --> G{"정책이 시작된 시점이 있고<br>안 받은 비교군이 있나?"}
    G -- 예 --> H["DID<br>사전 추세부터 확인"]
    G -- 아니오 --> I{"처치를 받은 사람과 비슷한<br>안 받은 사람을 찾을 수 있나?"}
    I -- 예 --> J["성향점수 매칭 (PSM)"]
    I -- 아니오 --> K["합성 통제 또는 시계열 예측 대비<br>결론 범위를 좁혀 보고"]
    D --> L{"트래픽이 부족한가?"}
    L -- 예 --> M["CUPED로 잡음 줄이기<br>또는 MDE를 다시 협의"]
    D --> N{"중간에 결과를 봐야 하나?"}
    N -- 예 --> O["순차 검정"]
```
