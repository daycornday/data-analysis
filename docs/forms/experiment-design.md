# 실험 설계서

> 실험을 시작하기 **전에** 채운다. 결과를 보고 나서 바꾼 항목은 결과 보고서에 "사후 변경"으로 따로 적는다.

## 1. 문제와 가설

- **문제** (현상 + 고칠 가치. 고치면 무엇이 얼마나 좋아지나)
- **가설** (무엇을 바꾸면, 누구의, 어떤 행동이, 왜 달라지나)
- **이 실험 전에 몰랐던 것** (방향은 예상되더라도 크기, 부작용, 대상, 지속성 중 무엇을 확인하려는가)

## 2. 지표

| 구분 | 지표 | 정의 (분자 / 분모 / 집계 단위) | 기대 방향 |
|---|---|---|---|
| 1차 지표 | | | |
| 2차 지표 | | | |
| 가드레일 | | | 나빠지면 이겨도 적용하지 않음 |

- 집계 단위와 배정 단위가 같은가? 다르면 분산 계산을 어떻게 할지 적는다

## 3. 설계

- **배정 단위** (유저, 기기, 세션, 매장, 지역)
- **그룹 구성과 비율**
- **대상과 제외 조건**
- **α / 검정력 / MDE와 그 근거**
- **그룹당 필요 표본과 기간** (`sample_size_per_group`, `days_needed`)
- **사전에 정한 하위그룹** (여기 없는 하위그룹은 결과에서 "탐색적"으로만 쓴다)

## 4. 판정 규칙 (실험 전에 합의)

- 1차 지표가 유의하고 가드레일이 비열세면 적용
- 가드레일이 임계치(______)를 넘으면 1차 지표와 관계없이 중단
- 결과가 음성이면 MDE와 신뢰구간 상한을 함께 보고

## 5. 반대 결과가 나오면

- 먼저 볼 것: 배정 로그, 그룹 표본 균형(SRM), 집계 기준
- 정상인데 대조군이 이겼다면 어떤 가설이 틀린 것으로 볼지
