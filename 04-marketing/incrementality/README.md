# 광고 증분 측정: 기여와 증분은 다른 질문이다

매체 리포트의 ROAS와 실험으로 잰 ROAS가 몇 배씩 다르게 나오는 걸 볼 때마다, 왜 그런지 깔끔하게 설명하지 못했습니다. 광고비를 늘릴지 줄일지 판단할 때 무엇을 봐야 하는지 궁금해서, 정답을 정해 둔 합성 데이터 안에서 측정 방법들을 하나씩 비교해 봤습니다.

## 왜 공부했나

기여(attribution)는 "일어난 전환을 채널에 어떻게 나눌까"에 답하고, 증분(incrementality)은 "광고가 없었다면 전환이 얼마나 줄었을까"에 답합니다. 예산을 판단할 때 필요한 것은 증분입니다. 그래서 증분을 재는 세 방법이 진짜 효과를 얼마나 되찾는지, 각각 비용이 얼마나 드는지를 한 세계 안에서 비교해 봤습니다.

## 결과

정리하면, 마지막 클릭 기여는 증분을 3.8배 부풀렸고 홀드아웃, 지역 실험, MMM은 정답 근처를 되찾았습니다. 다만 MMM은 채널 예산이 같이 움직이면 효과를 엉뚱한 채널에 나눠 줬습니다.

- 같은 소셜 캠페인이라도 ROAS가 기준에 따라 달랐습니다. 마지막 클릭 기여 9.79, 홀드아웃 증분 추정 2.76 (95% CI 1.94~3.58), 정답 2.54입니다. 기여 매출은 증분 정답의 3.8배였습니다.
- 유저 홀드아웃(20%)은 정답을 신뢰구간 안에 담았습니다. 대신 홀드아웃 39,828명에게서 증분 매출 약 956만 원을 포기해야 했습니다.
- 지역 실험(40개 지역, 사전 20주, 사후 8주)은 TV iROAS를 1.68 (95% CI 1.36~2.01)로 추정했습니다. 정답은 1.80입니다. 사전 기간 처치-통제 차이의 기울기는 -0.059/주 (p=0.20)여서 평행 추세 가정을 버릴 근거는 없었습니다.
- MMM(156주, 채널 3개)은 평균 ROI를 TV 1.79 (정답 1.80), 검색 1.02 (1.20), 소셜 2.53 (2.50)으로 추정했습니다. 검색 예산 30%를 소셜로 옮기면 주간 매출이 18.2백만 원 늘어난다고 예측했고, 정답 모델로 계산하면 19.4백만 원입니다.
- 같은 정답에서 채널 예산이 같이 움직이도록(상관 0.98~0.99) 만들자, MMM은 R2가 0.988로 오히려 높아졌는데도 검색 ROI를 2.36으로, 정답(1.20)의 2배로 추정했습니다. 적합도가 좋다고 채널 분리가 맞는 것은 아니라는 점이 가장 기억에 남았습니다.

## 어떻게 했나

### 정답 먼저 정하기

세 방법이 같은 세계를 재도록, 채널별 진짜 평균 ROI(증분 매출 / 광고비)를 먼저 정했습니다.

| 채널 | 정답 ROI | 측정 방법 |
|---|---|---|
| TV | 1.8 | 지역 실험, MMM |
| 검색 | 1.2 | MMM |
| 소셜 (리타겟팅) | 2.5 | 유저 홀드아웃, 마지막 클릭 기여, MMM |

데이터는 모두 `run.py`가 시드를 고정해 만든 합성 데이터입니다 (`data/`). 실제 기업 데이터는 쓰지 않았습니다.

### 1. 유저 단위 홀드아웃 (`lift.py`)

유저는 20만 명으로 두었습니다. 구매 의향은 유저마다 다르고(평균 구매율 4%), 광고는 구매 확률을 0.8%p 올리도록 했습니다.

유저마다 광고가 없을 때 결과 `y0`와 있을 때 결과 `y1`을 둘 다 만들었습니다. 그래서 진짜 증분 구매(`y1=1, y0=0`)를 셀 수 있습니다.

무작위 20%를 홀드아웃으로 떼고 광고를 보내지 않았습니다. 원래 살 사람도 60% 확률로 광고를 마지막에 클릭하고 사도록 했는데, 이런 구매도 매체 리포트에서는 광고 몫이 됩니다.

```
증분 매출 = (노출 그룹 유저당 매출 - 홀드아웃 유저당 매출) x 노출 유저 수
iROAS     = 증분 매출 / 광고비
신뢰구간  = 유저당 매출 차이의 Welch 정규 근사 구간을 같은 식으로 키운다
```

### 2. 지역 실험과 이중차분 (`geo.py`)

40개 지역 x 28주 매출 패널을 만들었습니다. 지역 규모는 제각각이고, 계절 흐름은 모든 지역에 같은 크기로 들어갑니다.

무작위로 고른 20개 지역에서 21주차부터 TV를 켰습니다. 광고비는 지역 규모의 4%, 증분은 광고비 x 1.8로 두었습니다.

효과는 지역, 주 고정효과 회귀로 추정하고, 표준오차는 지역 단위로 묶었습니다.

$$
\text{sales}_{rt} = \alpha_r + \gamma_t + \tau \cdot (\text{처치}_r \times \text{사후}_t) + \varepsilon_{rt}
$$

증분 매출은 tau x 처치 지역-주 칸 수, iROAS는 증분 매출 / 광고비로 계산했습니다.

사전 추세는 사전 기간의 주별 (처치 평균 - 통제 평균)을 주에 회귀해서, 기울기가 0과 다른지로 확인했습니다.

### 3. MMM (`mmm.py`)

주간 매출을 기본 수요와 채널 효과로 나눴습니다.

$$
\text{sales}_t = b_0 + b_1 \cdot \text{추세}_t + \sum_{h=1}^{2}\left(s_h \sin\frac{2\pi h t}{52} + c_h \cos\frac{2\pi h t}{52}\right) + \sum_{c} \beta_c \cdot S_c\left(A_{c,t}\right) + \varepsilon_t
$$

광고비는 두 가지 변환을 거칩니다.

```
이월 (adstock):  A_t = x_t + lam x A_{t-1}
포화 (hill):     S(A) = A^s / (A^s + K^s)       K는 adstock 평균의 배수로 둔다
```

기간은 156주(3년)입니다. TV는 4주 단위로 켜고 끄는 플라이트로, 검색과 소셜은 매주 무작위 금액으로 두었습니다.

정답 변환 모수는 TV (lam 0.65, K 1.2배, s 2), 검색 (0.1, 0.5배, 1), 소셜 (0.3, 1.6배, 2)입니다. 검색은 이미 포화된 채널로 설정했습니다. `beta`는 채널별 평균 ROI가 정답 ROI가 되도록 맞췄습니다.

추정은 lam 10개 x K 7개 x s 3개 격자에서 했습니다. 한 채널의 격자를 훑는 동안 다른 채널 값은 고정하고, 매 후보마다 나머지 계수는 최소제곱으로 풀었습니다. 이걸 채널마다 돌아가며 4바퀴 반복했습니다(좌표 하강). 채널 계수가 음수가 되는 후보는 버렸습니다.

채널 기여는 beta x S(A), 평균 ROI는 기여 합 / 광고비 합으로 계산했습니다. 반응 곡선은 매주 같은 금액 x를 계속 쓰는 정상 상태 (adstock = x / (1 - lam))를 기준으로 그렸습니다.

예산 재배분은 현재 평균 광고비에서 한계 ROI(1 더 쓸 때 늘어나는 매출)가 가장 낮은 채널의 예산 30%를 가장 높은 채널로 옮겨서 계산했습니다.

안정성을 보려고 광고비와 잡음 시드를 50번 바꿔 다시 추정하고 ROI의 5~95% 범위를 봤습니다.

마지막으로 채널이 같이 움직이는 경우를 보려고, 같은 정답과 같은 모델에 세 채널 광고비가 한 예산 흐름을 따르는 데이터를 넣어 봤습니다.

## 아쉬운 점과 다음에 해 볼 것

MMM은 실험 결과로 보정해야 한다는 점을 이번에 실감했습니다. MMM은 회귀라서 인과를 보장하지 않고, 실제로 검색 ROI가 시드에 따라 0.26~2.48로 흔들렸습니다. 홀드아웃이나 지역 실험으로 얻은 채널 iROAS를 사전 정보나 제약으로 넣어 MMM을 맞추는 것이 정석이라고 하는데, 여기서는 그 보정 단계까지 구현하지 못했습니다.

채널이 같이 움직이면 분리가 어렵습니다. 예산이 한 흐름으로 늘고 줄면 R2가 높아도 채널별 효과는 엉뚱하게 나뉩니다. 데이터를 더 모으는 것보다 일부러 채널 예산을 따로 흔드는 기간(실험)을 만드는 편이 나아 보입니다.

정답 세계가 모델과 같은 모양(adstock + hill)이라 MMM에 유리한 설정이었습니다. 실제 매출에서는 가격, 프로모션, 경쟁사, 휴일 같은 변수가 빠지면 그 몫이 광고 효과로 새어 들어갑니다.

홀드아웃에서는 광고 효과가 모든 유저에게 같다고(0.8%p) 두었습니다. 실제로는 의향이 높은 유저에게 효과가 작은 경우가 많아서, 타겟팅 정책에 따라 iROAS가 달라질 것으로 보입니다.

지역 실험에는 지역 사이 이동(통제 지역 유저가 처치 지역 광고를 보는 경우)과 지역별로 다른 추세를 넣지 않았습니다. 지역 수가 적으면 합성 통제(synthetic control)를 함께 쓴다고 해서, 다음에 같이 다뤄 보고 싶습니다.

MMM 추정에는 신뢰구간 대신 시드 반복 범위를 썼습니다. 베이지안 MMM(Meridian, PyMC-Marketing)은 사후분포로 불확실성을 직접 준다고 해서 이것도 다음 공부거리로 남겨 둡니다.
