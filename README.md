# Data Analysis

데이터 분석가로 일하면서 "이거 제대로 한 게 맞나?" 싶었던 질문들을 공부하고 정리하는 곳입니다.

실험 결과를 보고하거나 지표를 만들다 보면, 방법은 알아도 왜 그렇게 해야 하는지 설명하기 어려운 순간이 자주 옵니다. 그럴 때마다 교재와 논문을 찾아 읽고, 직접 데이터를 만들어 돌려 보면서 이해한 내용을 여기에 남기고 있습니다. 회사 데이터는 쓸 수 없어서 공개 데이터나 직접 만든 가상 데이터로 다시 풀어 봤습니다.
