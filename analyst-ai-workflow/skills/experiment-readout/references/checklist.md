# 실험 결과 체크리스트

순서대로 본다. "멈춤"이 걸리면 아래 단계로 내려가지 않는다.

## 1. 데이터 품질
- [ ] 그룹별 사용자 수 SRM 검정 p >= 0.001 (아니면 멈춤)
- [ ] 배정 단위와 분석 단위가 같다 (사용자 배정이면 사용자 단위 분석)
- [ ] 실험 기간이 계획과 같고 요일 주기를 한 바퀴 이상 덮는다
- [ ] 두 그룹에 같은 필터(봇, 내부 계정, 테스트 계정 제외)를 걸었다
- [ ] 실험 시작 전 기간에 두 그룹 지표가 비슷하다 (A/A 성격 확인)

## 2. 검정력
- [ ] 사전 계산한 표본 수에 도달했다
- [ ] 유의하지 않은 결과를 "효과 없음"이 아니라 "MDE 이하 효과는 판별 불가"로 썼다
- [ ] 사후 검정력(관측 효과로 계산)을 쓰지 않았다

## 3. 1차 지표
- [ ] 절대 차이, 상대 차이, 95% 신뢰구간을 모두 썼다
- [ ] 비율 지표의 분산을 배정 단위 기준으로 구했다 (필요하면 델타 방법)
- [ ] 극단값 처리(윈저화 등)를 했다면 기준을 사전에 정했고 보고서에 적었다

## 4. 다중 비교
- [ ] 2차 지표 수와 보정 방법(Holm 또는 BH)을 적었다
- [ ] 사후에 고른 세그먼트는 "탐색"으로 표시했다
- [ ] 중간에 결과를 여러 번 봤다면(엿보기) 순차 검정 보정을 했거나 그 사실을 적었다

## 5. 가드레일
- [ ] 사전에 정한 가드레일 지표를 모두 보고했다
- [ ] 가드레일 판정 기준(허용 악화 폭)을 적었다

## 6. 해석과 결정
- [ ] 통계적 유의와 실무 유의를 나눠 썼다
- [ ] 신뢰구간 하한을 출시 비용 기준선과 비교했다
- [ ] 주차별 효과 추이로 노벨티 효과를 확인했다
- [ ] 결정이 출시, 중단, 재실험 중 하나로 적혀 있다
- [ ] `[확인 필요]` 표시가 남아 있지 않다
