# 글 양식

## 머리말
```
---
title: N. 제목 (번호로 시작)
category: 실험 설계 | 기초 통계 | 인과추론 | 지표 설계 중 하나
tags: 3~10개, 쉼표로 구분
---
```

## 본문 순서
1. `## 들어가며`: 이 개념이 실무 어디서 필요한지 두세 줄. 질문으로 시작해도 좋다
2. 개념 섹션 2~4개 (`##`, 필요하면 `###`까지). 각 섹션은 비유 한 개, 예시 한 개
3. 숫자 예시: 실행한 코드와 그 출력만
4. `## 정리`: 세 줄 이내
5. `## 더 읽을 것`: 링크 1개 이상

## 문체
- 짧은 문장, 결론 먼저
- 홍보 문구와 이모지를 쓰지 않는다
- 나열은 쉼표나 줄바꿈으로

## 자동 검사 (automation/check_doc.py)
| 항목 | 기준 |
|------|------|
| 머리말 | title, category, tags 있음, 태그 3~10개 |
| 섹션 | 들어가며, 정리, 더 읽을 것 |
| 링크 | 더 읽을 것에 1개 이상 |
| 금지 문자 | 가운뎃점(U+00B7)과 비슷한 점, 폭 없는 공백 |
| 금지어 | `hooks/banned_words.txt` 또는 BANNED_WORDS_FILE |
| 사람 확인 표시 | `[확인 필요]` 0개 |
| 길이 | 본문 1500~12000자 |
| 제목 깊이 | `###`까지 |

검사로 잡을 수 없는 것은 사람이 본다: 숫자가 실제 실행 결과인지, 비유가 개념을 왜곡하지 않는지.
