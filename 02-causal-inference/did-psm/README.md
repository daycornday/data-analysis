# 무작위 배정 없이 효과 추정하기: DID와 PSM

> 한 줄 요약: 실험을 못 할 때 관측 데이터로 효과를 구할 수 있는지 공개 데이터 두 개로 재현했다. DID는 캘리포니아 정책 효과를 -2.25%p로, PSM은 직업훈련 효과를 +$1,775로 추정했고, PSM은 실험 정답(+$1,794)에 가까웠지만 모델 사양에 따라 +$1,551에서 +$2,074까지 움직였다.

## 질문

기능을 한 지역에만 먼저 배포했거나, 유저가 스스로 기능을 골라 썼다면 A/B 테스트처럼 무작위로 나눈 대조군이 없다. 그래도 "그 변화가 지표를 얼마나 움직였나"는 답해야 한다. 이 폴더는 그때 쓰는 대표 방법 두 가지가 실제로 정답에 얼마나 가까운지를 공개 데이터로 확인한다.

- DID: 처치가 특정 시점에 특정 집단에만 들어갔을 때 ("언제 무엇이 바뀌었나")
- PSM: 처치를 받은 사람이 스스로 선택했을 때 ("누가 그 행동을 했나")

## 결론

- DID: 캘리포니아의 "능동적 선택" 기증 등록 방식은 등록 동의율을 **-0.0225 (약 -2.25%p)** 바꿨다. 주 단위 클러스터 표준오차 0.0061, p = 0.0002. 2x2 손계산과 회귀 계수가 같다.
- DID 사전 추세: 정책 전 세 분기 격차는 -0.178, -0.168, -0.175로 거의 일정했다. 다만 이벤트 스터디의 k = -2 계수(+0.0063)는 신뢰구간이 0을 살짝 벗어났다.
- PSM: 단순 비교는 **-$8,498**로 부호까지 틀렸고, 1:1 최근접 매칭 후 ATT는 **+$1,775**로 실험 정답 **+$1,794**에 가까웠다. 매칭 후 7개 공변량의 |SMD|는 모두 0.17 이하로 줄었다.
- PSM 추정치는 성향점수 모델에 민감했다. 공변량 구성만 바꿔도 +$1,551에서 +$2,074까지 움직였다. 숫자 하나보다 사양별 범위를 같이 보고해야 한다.

## 방법

두 방법 모두 "처치를 받지 않았다면 어땠을지(반사실)"를 대조군으로 채운다. 채우는 방식과 필요한 가정이 다르다.

### DID

데이터: 미국 27개 주의 분기별 장기기증 등록 동의율 (2010년 4분기에서 2012년 1분기, 6분기). 캘리포니아가 2011년 3분기에 등록 문구를 "능동적 선택" 방식으로 바꿨다. 대조군은 정책을 바꾸지 않은 나머지 26개 주다.

1. 2x2 표: 집단(처치, 대조)과 기간(전, 후)별 평균을 구하고 두 번 뺀다.

$$
\text{DID} = (\bar{Y}_{\text{처치, 후}} - \bar{Y}_{\text{처치, 전}}) - (\bar{Y}_{\text{대조, 후}} - \bar{Y}_{\text{대조, 전}})
$$

2. 회귀: 같은 값을 상호작용항 계수로 구하고, 같은 주가 여러 분기 관측되므로 주 단위 클러스터 표준오차를 쓴다.

```
Rate ~ Treated + Post + Treated:Post      # Treated:Post 계수 = DID
```

3. 사전 추세 확인: 정책 전 세 분기의 집단별 기울기와 분기별 격차를 본다.
4. 이벤트 스터디: 주 고정효과와 분기 고정효과를 넣고, 정책 직전 분기(k = -1)를 기준으로 분기마다 처치군과 대조군의 차이를 따로 추정한다.

$$
Y_{it} = \alpha_i + \lambda_t + \sum_{k \neq -1} \delta_k \cdot \text{Treated}_i \cdot \mathbb{1}(t - t_0 = k) + \varepsilon_{it}
$$

k < 0 의 계수가 0 근처면 평행 추세를 지지하는 증거가 된다.

### PSM

데이터: LaLonde(1986)의 NSW 직업훈련 데이터 중 Dehejia & Wahba(1999) 표본. NSW는 원래 무작위 배정 실험이라 실험 정답이 있다. 실험 대조군 대신 일반 인구 표본(CPS) 15,992명을 대조군으로 붙여, 관측 데이터 방법이 정답을 얼마나 되찾는지 시험한다.

1. 실험 정답: NSW 처치군 185명과 실험 대조군 260명의 1978년 소득 평균 차.
2. 단순 관측 비교: NSW 처치군 185명과 CPS 15,992명의 평균 차.
3. 성향점수: 로지스틱 회귀로 훈련 참가 확률을 추정한다. 공변량은 나이(age), 교육 연수(educ), 흑인 여부(black), 결혼(marr), 무학위(nodegree), 1974년 소득(re74), 1975년 소득(re75).

$$
e(X) = P(T = 1 \mid X)
$$

4. 매칭: 처치군 한 명마다 성향점수가 가장 가까운 CPS 대조군 1명을 고른다 (1:1, 복원 매칭, 캘리퍼 없음).
5. 균형 점검: 공변량마다 매칭 전후 표준화 평균 차이(SMD)를 계산한다. |SMD| < 0.1 을 균형 기준으로 본다.

$$
\text{SMD} = \frac{\bar{X}_{\text{처치}} - \bar{X}_{\text{대조}}}{\sqrt{(s^2_{\text{처치}} + s^2_{\text{대조}}) / 2}}
$$

6. ATT: 처치군 평균 소득 - 매칭된 대조군 평균 소득.
7. 사양 민감도: hisp 추가, 제곱항(age, educ)과 무소득 더미(re74 = 0, re75 = 0) 추가로 모두 4개 사양의 ATT를 비교한다.

- 정책 전 분기당 기울기: 캘리포니아 +0.0038, 다른 주 +0.0024

해석: 캘리포니아만 보면 정책 후 0.85%p 떨어졌다. 같은 기간 다른 주는 1.39%p 올랐으니, 정책이 없었다면 캘리포니아도 비슷하게 올랐을 것으로 본다. 그 차이인 -2.25%p가 정책 효과다. 이벤트 스터디에서 정책 후 세 분기 계수가 모두 -0.020에서 -0.022로 비슷해, 효과가 한 분기에 몰린 것이 아니라 꾸준히 이어졌다.

평행 추세는 완벽하지 않다. 정책 전 캘리포니아가 조금 더 가파르게 오르고 있었고(+0.0038 대 +0.0024), k = -2 계수는 0과 통계적으로 구분됐다. 다만 캘리포니아가 더 빨리 오르던 흐름이 이어졌다면 반사실은 더 높았을 것이므로, 이 어긋남은 효과를 작게 잡는 방향이다. -2.25%p는 보수적인 추정에 가깝다.

매칭 전에는 대부분 |SMD|가 0.5를 넘었고, 매칭 후 크게 줄었다. 그래도 nodegree, age, educ, marr 네 개는 0.1을 넘는다. 균형이 일부 남은 상태의 추정치다.

## 한계와 다음 단계

- DID의 처치군은 캘리포니아 하나다. 처치 클러스터가 1개면 클러스터 표준오차가 실제 불확실성을 작게 잡을 수 있다. 다음 단계는 대조 주를 하나씩 처치군으로 바꿔 보는 위약(placebo) 검정이나 합성 대조군(synthetic control)이다.
- DID 사전 기간이 세 분기뿐이라 평행 추세의 증거가 약하다. 같은 시기 캘리포니아에만 있었던 다른 변화도 이 데이터로는 배제하지 못한다.
- PSM은 측정한 변수만 맞춘다. 의욕처럼 데이터에 없는 교란은 보정하지 못한다. Rosenbaum bounds 같은 민감도 분석을 붙이지 않았다.
- PSM 표준오차와 신뢰구간을 계산하지 않았다. 복원 매칭이라 단순 t검정은 맞지 않고, 부트스트랩이나 Abadie-Imbens 표준오차가 필요하다.
- 균형이 덜 맞은 변수가 남았다. 캘리퍼 매칭, 역확률 가중(IPW), 회귀 보정을 더해 사양별 범위가 좁혀지는지 보는 것이 다음 단계다.
- 실험 정답이 있는 데이터라서 PSM이 정답에 가까운지 확인할 수 있었다. 실무 데이터에는 정답이 없으므로, 사양 민감도와 균형표를 함께 보고하는 습관이 더 중요하다.

## 실행

```
pip install -r ../../requirements.txt
python run.py
python -m pytest tests
```

run.py는 `data/`의 csv 세 개를 읽어 `outputs/`에 그림 4개와 표(csv, `results.md`)를 만든다. 일반 노트북에서 10초 안에 끝난다. 데이터 처리에 난수를 쓰지 않으므로 실행할 때마다 같은 숫자가 나온다. tests는 합성 데이터에 넣은 효과(DID -0.03, PSM +2.0)를 함수가 되찾는지 확인한다.
